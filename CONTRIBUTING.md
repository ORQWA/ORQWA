Setup, checks and builds run in a dev container: see [docs/development.md](docs/development.md).
Conventions are in [CLAUDE.md](CLAUDE.md), architecture decisions in [docs/adr/](docs/adr/) and
third-party assets in [docs/CREDITS.md](docs/CREDITS.md).

## Contributor License Agreement

Before your first pull request can be merged, please accept the
[Contributor License Agreement](CLA.md). A bot asks you on the pull request and signing takes
one click. You only do it once.

You keep the copyright in your work. The CLA lets the maintainer adjust ORQWA's licensing,
for example to add an exception so ORQWA can ship through app stores, without asking every
contributor again. In return, ORQWA stays available under an open-source license (CLA
section 4). [ADR 0044](docs/adr/0044-contributor-license-agreement.md) explains why.
